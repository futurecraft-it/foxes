foxes is a plugin that allows player to tame fox. Once a fox is tamed (by feeding them with raw chicken) it will drop it's untamed behavior and will start to follow the owner, attacking targets just like wolves and will lie on "warn" block (lit furnaces or beds) just like cat does. Default "trusted player" feature is still aviable.

More animals will be added later.
